# midterm151

Bootstrap 5.3.8 網頁作業，包含 4 張輪播圖片、4 張 Cards 與指定頁尾資料。

## 發佈到 GitHub Pages
1. 建立 GitHub repository：`midterm151`。
2. 將 `index.html` 上傳到 repository 根目錄。
3. 開啟 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選 `main`、資料夾選 `/(root)`，按 **Save**。
6. 等待 GitHub Pages 完成部署。
